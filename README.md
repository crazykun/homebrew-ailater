# homebrew-ailater

[LaterScreen](https://github.com/crazykun/LaterScreen)（`lscreen`）的个人 Homebrew tap——跨平台截图标注工具：截图、标注、取色、二维码识别、OCR、录屏。

## 安装

```bash
brew tap crazykun/ailater
brew install lscreen
```

或一步到位：

```bash
brew install crazykun/ailater/lscreen
```

## 使用

- `lscreen` —— 静默驻留后台托盘（默认 F1 触发截图）
- `lscreen gui` —— 立即进入截图
- `lscreen --help` —— 全部子命令

## 更新

发新版后本 tap 的 Formula 会同步更新：

```bash
brew update && brew upgrade lscreen
```
